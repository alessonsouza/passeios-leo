# Passeios — LEO Clube Ômega

Site dos passeios e excursões do **LEO Clube Ômega Pinhalzinho-SC**. Apresenta os passeios disponíveis em cards e permite a inscrição direto na página, com modal de cadastro e confirmação visual.

**No ar:** https://passeiosconfepzo.ascorp.app

## O que tem

- Listagem de passeios em cards (`PasseioCard`).
- Modal de inscrição com validação (`InscricaoModal`) e overlay de sucesso (`SuccessOverlay`).
- Hero e layout responsivo.

## Stack

React 19 + TypeScript + Vite, estilos em CSS.

## Desenvolvimento

```bash
bun install
bun run dev       # servidor de desenvolvimento
bun run build     # type-check + build de produção
bun run preview   # pré-visualizar o build
bun run lint      # eslint
```
